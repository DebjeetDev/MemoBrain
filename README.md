## 📖 About
MemoBrain is a web app that helps students and learners
memorise anything using flashcards and quizzes.
I built this to make studying more interactive and fun.
## ✨ Features
- 🃏 Create and flip custom flashcards
- 🧠 Quiz yourself with instant right/wrong feedback
- 📊 See your score at the end of every quiz
- 📱 Works on mobile too
